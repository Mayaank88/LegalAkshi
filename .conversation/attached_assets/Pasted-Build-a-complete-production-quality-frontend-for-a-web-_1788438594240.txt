Build a complete, production-quality frontend for a web application called "NutriCheck" (designed with easy-to-change branding tokens).

The application's PRIMARY CORE PURPOSE is to analyze packaged food products, beverages, dietary supplements, and FMCG items sold in India for strict compliance with Indian Regulatory Laws, primarily the **Legal Metrology (Packaged Commodities) Rules, 2011** and **FSSAI Labelling & Display Regulations**. While nutrition and health scores are analyzed, the main focus is regulatory compliance, violation detection, and consumer protection.

IMPORTANT:
This is ONE complete, cohesive website. Do NOT divide the project into standalone modules owned by different developers. The entire website must share one unified design system and feel like a polished, commercial-grade product.

==================================================
TECH STACK

- React

- JavaScript / JSX

Keep dependencies minimal, clean, and modern. Utilize reusable components and a clean folder structure.

Ensure local state / Mock API services store newly added inspector rules so that running a new scan immediately evaluates against both built-in and newly added rules!
